# Paperleaf v1.2.0

发布日期：2026-11-04。

## 更新

- 新增竖向连续阅读 / 横向翻页切换与本机阅读偏好，按需渲染附近页；阅读进度继续同步云端。
- 优化文献库与阅读器的字体、对比度、工具栏和笔记侧栏，保留划词无重影修复。
- 新增版本检查、版本说明、下载进度、取消、SHA-256 校验和「退出并安装」。
- 修复 Windows 沙箱不支持根目录禁止读取的权限组合导致无法创建 Codex 会话的问题。改为兼容的只读权限，禁用项目指令发现和工具；不使用无沙箱回退。
- 新增「测试 GPT」，实际发送示例英文并显示模型回复。
- 安装器改用 solid LZMA 压缩，移除未使用的 Chromium 语言包；保留中英文和完整 Codex 组件，并加入 245 MiB 构建与发布体积上限。

## 测试

真实账号通过应用 HTTP 连接程序完成了翻译、引用问答、文献信息识别、总结与 6 页汇报内容生成，使用 gpt-6.1-sol 和示例文献。Windows GitHub Actions 的真实 Codex 会话创建及更新校验已通过。发行后自动安装 EXE 并运行其内置 Codex；可在仓库 Actions 查看结果。GUI 登录、实际用户的 Windows 网络配置不在自动测试覆盖范围。
