# Paperleaf 1.4.2 · 阅读批注与上下文追问

发布日期：2026-11-05。Windows 10 / 11 x64，EXE 安装向导。Electron 45.2.2，官方 Codex 0.165.0。

## 本次更新

- **拖动与缩放论文**：使用“拖动论文”工具，或按住空格拖动阅读页；Ctrl / ⌘ + 鼠标滚轮以指针为中心缩放，范围 50%–250%。
- **PDF 画笔与文本框**：直接在页面上画线、添加文本；文本框可移动和调整大小。提供颜色、笔宽、橡皮、撤销/重做、云端保存与批注 JSON 导出。
- **重新整理笔记界面**：更大的编辑区与卡片留白，正文行距更舒适；长摘录默认收起，支持搜索和按时间/页码排序。
- **笔记与翻译追问**：笔记草稿、已保存笔记、选词译文、历史译文与全文段落都可继续问 GPT，携带原文、笔记或译文、相关页码和有限近期对话，按文献独立保存。
- **全文翻译优先正文**：根据文字坐标恢复双栏顺序与段落，修复断词，优先摘要和正文，过滤重复页眉页脚、前置作者信息与参考文献。可改选“全部文字”；不同范围和旧版译文分别保存。
- **新的桌面安装包**：程序、连接状态、快捷方式和更新元信息统一升级到 1.4.2；继续使用 Paperleaf 图标及既有本机授权目录。

## 安装与更新

下载 Release 附件中的 **Paperleaf-Setup-1.4.2-Windows-x64.exe**。关闭旧版后双击安装，无需解压 ZIP。支持应用内“版本与更新”检查新版、查看更新说明、下载并校验后安装。保留原账号与云端资料。

桌面版从同一 HTTPS 网站加载阅读界面，需联网。安装包目前尚未代码签名。

## 已知边界

批注独立保存，**下载原始 PDF 不包含批注**。复杂版式仍可能分段不准，扫描件需先 OCR。拖动、缩放及批注对齐的可视化交互仍需登录后的 Windows/浏览器检查；当前环境的托管预览不可连接，自动化逻辑检查不能替代视觉验收。Windows 交互式 OAuth 与用户本机网络不在自动安装检查覆盖范围。

额度刷新接口在之前测试账号返回 HTTP 401；失败或旧数据会明确显示，不冒充刷新成功。模型只在实际提供公开摘要时显示摘要，不保证每次返回。
