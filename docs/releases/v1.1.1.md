# Paperleaf v1.1.1

## 修复与改进

- 修复 GPT 翻译、问答、总结、智能导入与 PPT 生成时的 `readOnly.access is no longer supported` 错误：改用当前 Codex 支持的受限权限配置，保留工具禁用与只读边界。
- 修复 PDF 划词时文字重影：选区只显示高亮背景，原文字体继续由 PDF 画布绘制。
- 提供 Windows x64 `.exe` 安装向导，支持选择安装目录、桌面/开始菜单快捷方式与卸载，无需解压 ZIP 或另装 Node.js。
- 为旧桌面版与浏览器连接程序增加明确的升级提示。
- 保留已有云端文献、笔记、阅读进度、翻译历史，以及同一电脑的账号目录。

## 下载与升级

下载本页 Assets 中的 **Paperleaf-Setup-1.1.1-Windows-x64.exe**。关闭旧版，双击安装，完成后从新快捷方式启动。以前的免安装文件夹无需继续使用。使用原来的 Paperleaf 账号；新电脑仍需登录 Codex。

网页版：https://paperleaf-xcz-reader.shamboo2003.chatgpt.site
