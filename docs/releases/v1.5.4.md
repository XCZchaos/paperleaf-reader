# Paperleaf 1.5.4 · 边分段边翻译

在「翻译 → 全文中英对照」选择「AI 自然段 · 论文正文」后，GPT 先核对开头的两个片段。第一段的边界确认后，界面就逐字显示译文。当前段开始出字后，如果后面还没有确认好的段落，可以同时检查下一批原文。

- 跨页、跨栏的尾句会等后文确认后一起翻译。段落内被误并的内容仍可按原文拆开。
- 翻译参考相邻段落和已有译文中的术语。可以随时暂停，已确认的分段和已保存的全文译文都能续用。
- 「论证精读」同步提前显示译文和批注，完成所有段落后再生成全文总览。「仅运行 AI 分段」仍可单独使用。

连接面板默认采用 Codex 内置的 OpenAI 连接，也可以手动选择 HTTP 流式兼容模式。新版本的「测试 GPT」仅发送「请只回复 OK」。普通 HTTP 429 和 Codex 明确报告的使用上限会分别显示。

模拟模型与 SQLite 集成测试覆盖首段先于全文分段就绪、跨批次续接、暂停恢复、不同窗口的分段冲突、旧译文复用及按段保存。另用真实 Codex 0.165.0 测试了两种连接的会话创建。真实账号的响应时间、译文质量和此前 429 的具体原因仍待在线验证。
