# Paperleaf 1.5.2

## 论文分段检查

阅读器先在本机分析 PDF 文本的位置、字号、栏间留白和图注的行距，再将整段原文交给 Codex。正文模式将识别出的图注与正文分开。选择「全部可提取文字」可查看独立的图注。打开 **论证精读 → 精读设置 → 分段检查**，可以查看疑似独立编号、断句或表格行的页码，点击「定位原文」即可核对。这个检查不使用模型额度。

已有草稿可以继续打开和导出。先导出希望保留的版本，再点「按自然段重新提取」即可应用新版规则。保存到云端仍由读者决定。图片型扫描件需先做 OCR。复杂公式的上下标和表格的合并单元格仍应对照 PDF。

## Mac 客户端更新

从 **1.5.2** 起，进入 **Paperleaf → 检查更新与版本说明 → 下载新版本**。客户端选择本机芯片对应的 PKG，显示下载进度，核对大小及 SHA-256。保存手头工作，点击「退出并打开 Mac 安装器」，在 macOS 安装器中确认安装，随后从「应用程序」打开 Paperleaf。Mac 1.5.0 和 1.5.1 需要手动安装此次升级。Windows 继续使用原有的 EXE 更新流程。

当前 Mac 应用使用 ad-hoc 签名，PKG 尚无 Apple Developer ID 签名与公证。macOS 会按本机安全策略处理下载的安装包。受单位管理的电脑可能需要管理员批准。

## 样本验证

测试程序调用发行版的 PDF.js 和正文提取逻辑，对论文原文中的固定片段、阅读顺序和分批结果作断言。复核提示数只代表启发式检查标出的候选。测试不评价整篇译文的学术质量。

| PDF 样本 | 页数 | 验证内容 |
| --- | ---: | --- |
| MIND，12 页出版稿 | 12 | 第 4 页绕图正文首尾相连，图注单独保留，公式（4）和前后说明同段 |
| Attention Is All You Need，NeurIPS | 11 | 单栏摘要及正文范围，排除参考文献 |
| BERT，ACL | 16 | 双栏摘要的首句和结尾数据在同段 |
| Dropout as a Bayesian Approximation，ICML | 10 | 双栏摘要及其结尾陈述在同段 |
| Observation of Gravitational Waves，Physical Review Letters | 16 | 无标题摘要以及无标题编号参考文献的边界 |
| Ten Simple Rules for Reproducible Computational Research，PLOS | 4 | 三栏阅读顺序以及同栏段落的首尾 |

运行 `node scripts/check-paper-layouts.mjs` 可以复测五篇公开样本。可以传入装有固定版本 PDF 的目录离线执行。运行 `node scripts/check-argument-paragraphs.mjs <MIND出版稿PDF路径>` 复测绕图、公式、扫描页间断、列表和跨页续写。用户的论文不会随测试提交到仓库。

两种架构的原生 Mac 测试都从实际的 1.5.1 应用升级到 1.5.2，经过新版更新逻辑的下载与校验、系统安装引擎、签名检查与本机资料保留检查。交互式系统安全提示由读者的 Mac 决定。[Mac 构建与升级记录](https://github.com/XCZchaos/paperleaf-reader/actions/runs/44450497289)
