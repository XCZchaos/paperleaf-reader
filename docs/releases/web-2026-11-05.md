# Reading workspace · 2026-11-05

Hosted frontend/API update for Paperleaf; desktop binary stays at 1.4.1.

## Changes

- Hand-tool and Space-drag panning; pointer-anchored Ctrl/Meta-wheel zoom, clamped to 50–250%, scoped to the PDF viewport.
- Cloud-backed pen and text annotations using normalized page coordinates. Movable/resizable text boxes, color/width tools, eraser, undo/redo and JSON export. The original PDF remains unchanged.
- Spacious notes editor and shadcn cards, collapsible source excerpts, search and sorting.
- Contextual GPT conversations on note drafts, saved notes, translation selections/history and full-text paragraphs. Source context and parent/conversation scope are validated on the API and retained on reopen.
- Body-first paragraph preparation uses coordinates, column order, indentation, hyphen repair, repeated margin detection and abstract/reference section boundaries. Full extracted text is an alternative; legacy and new modes have separate queues and saved results.

## Limits and delivery

Browser interaction QA could not run against the managed preview: the service reported its preview URL but the cloud browser received `ERR_CONNECTION_REFUSED`. The public production page loads but the reader requires the user's separate Paperleaf login. Gesture behavior, responsive layout and visual annotation alignment therefore still need a signed-in browser/Windows check. The production build and API/logic/live-model checks do not substitute for that check.

Annotations are a separate overlay, not embedded into downloaded PDFs. Text-box text is capped at 5,000 characters; a document supports up to 500 annotations within a 600 KB record budget. Recent undo history is local to the open reading session. Body recognition is heuristic; complex layouts and image-only content can require the all-text mode or OCR. Very long source context is visibly excerpted before being sent to GPT.

Migrations `0007` and `0008` add contextual conversation metadata and separate translation extraction modes. Existing translations default to the legacy mode and remain available. Recovered installer bytes match the published 1.4.1 SHA-256; the desktop update feed continues serving the same verified binary.
