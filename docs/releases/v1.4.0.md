# Paperleaf v1.4.0

## 阅读与复习

- 新增云端单词本：划译一个英文单词后，由 GPT 判断是否为单词，并整理词性、释义、文献语境、自拟例句、相关词及完整解释。默认自动收录，可关闭并改用手动加入。
- 重复单词合并，保留学习状态与最近 20 次原文来源；支持中文/英文搜索、待复习/已掌握、跳回文献页和导出。
- 新增全文翻译：按 PDF 文本布局分段，原文与中文逐段对应。逐段保存、暂停后继续、失败重试、导出；扫描页提示需要 OCR。
- 问答支持持续追问与独立对话历史；重新打开后继续，云端保存失败可重试而不重复调用模型。上下文携带最近最多 20 轮及有界文字，更早记录保存在历史中。

## 模型与界面

- 采用 shadcn/ui 统一按钮、卡片、表单、标签页、开关、进度条与弹窗；重排文献库、阅读侧栏、单词本及登录注册页面，支持纸白/夜读主题。弹窗管理焦点与键盘，切换阅读工具时不会误翻 PDF 页。

- 翻译提供轻量模型建议，识别、问答、总结与 PPT 提供各自模型/思考强度建议，且只推荐当前账号可用选项。各功能选择独立保存，速度仍受输入、网络和服务负载影响。
- 显示真实 Codex 公开进展、计划与重试事件；有公开思考摘要时显示，不读取或展示原始内部推理。
- 修复中文标点紧邻 Markdown 加粗的显示；优化回答排版。
- 导入分析期间窗口尺寸固定、队列内部滚动，长文件名与状态不会撑开窗口。
- Windows EXE、安装器、桌面与开始菜单快捷方式使用 Paperleaf 图标；版本化图标路径帮助避免旧快捷方式图标缓存。

## 安装与更新

下载 `Paperleaf-Setup-1.4.0-Windows-x64.exe`，直接运行向导；无需解压 ZIP。1.2.0/1.3.0 桌面版也可通过「检查更新」查看说明、下载并安装。安装保留账号资料。桌面版本尚未代码签名。

## 验证范围

- 真实 Codex：gpt-6.1-sol 通过两轮记忆问答、段落翻译、元信息识别、总结与 6 页汇报；gpt-6-luna（low）通过单词与短语识别。
- 自动化：Markdown 渲染/安全、API 账号隔离、对话关联、翻译租约/幂等保存/重试、单词去重/掌握状态/来源、桌面包和更新器。
- 浏览器：明确标注的合成测试材料验证连续追问、保存重试、翻译续传、单词收录/搜索/掌握状态与导入布局稳定；新版界面验证主题切换、登录/注册标签页、弹窗焦点恢复及阅读工具键盘导航。
- 当前模型没有返回公开思考摘要，因此不承诺每次都能显示摘要。Windows 交互式 OAuth 和用户特定网络不在容器测试范围；发行包另由 GitHub Actions 检查 Windows 安装、图标与 Codex 启动。
