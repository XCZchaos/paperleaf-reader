# Paperleaf 1.4.3 · 划词暂存与流式阅读

发布日期：2026-11-06。Windows 10 / 11 x64，EXE 安装向导。Electron 45.2.2，官方 Codex 0.165.0。

## 本次更新

- 划选英文自动打开翻译区并翻译；新选区替换当前临时结果。生成中再次划选会提示“上一段内容正在翻译，请稍等”，保留原任务。
- **Shift 暂存**：点按开启后只暂存选文，可来自同页或多页；再次点按关闭后立即翻译。界面显示暂存状态、片段数和来源页。
- 移除“自动划译”“连续翻译”两个开关与追加队列。划词译文不主动上传云端、不自动加入单词本；需要保留时主动保存双语笔记或收录单词。全文翻译和对话仍保留其明确的云端保存功能。
- 未连接 Codex 时显示连接提示，保留当前选区；连接成功后自动开始。
- 阅读栏和批注栏的分隔线可调整高度，页码、阅读方式和工具组可调整宽度。支持拖动、键盘调整、双击复位和本机尺寸记忆。返回文献库是清晰的按钮。
- 修复卡片滚动到边界后卡住的问题。流式输出减少重复渲染，优先响应输入与滚动；向上阅读时暂停自动跟随，点击“查看最新译文”恢复跟随。
- **桌面版优先发布**：本次提供 1.4.3 EXE 和应用内更新。公共网页仅提供下载、版本说明和安装指引；阅读工作台由桌面端进入，继续保留原云端账号与资料。

## 安装与更新

关闭旧版后运行 **Paperleaf-Setup-1.4.3-Windows-x64.exe**，无需解压 ZIP。也可在桌面菜单“检查更新与版本说明”中下载、校验并安装。保留原本机授权目录和云端文献。

[桌面下载与说明](https://paperleaf-xcz-reader.shamboo2003.chatgpt.site/) · [GitHub Release](https://github.com/XCZchaos/paperleaf-reader/releases/tag/v1.4.3)

桌面程序仍需联网，从现有 HTTPS 来源加载阅读界面并访问云端 API。安装包尚未代码签名。
