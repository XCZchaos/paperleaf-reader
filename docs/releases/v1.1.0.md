# Paperleaf v1.1.0 · 云端账号与 Windows 桌面预览版

网页版：https://paperleaf-xcz-reader.shamboo2003.chatgpt.site

## 这一版包含

- Paperleaf 用户名/密码注册与登录、恢复码、修改密码和其他设备会话撤销。
- PDF、文献信息、笔记与草稿、阅读进度、翻译会话和 GPT 记录云端保存。
- Windows x64 桌面客户端，内置 Electron 45.2.2 和官方 Codex 0.165.0。
- 通过系统浏览器进行 Codex 官方账号授权，无需手动启动连接程序或填写配对码。
- 延续 PDF 阅读、GPT 元信息识别与命名、划词/连续翻译、问答总结、PPTX 汇报导出。

## 下载与使用

`Paperleaf-Desktop-1.1.0-Windows-x64.zip`（310.8 MiB，325,937,878 字节）适用于 Windows 10/11 x64。

1. 完整解压，双击 `Paperleaf.exe`，保留所有配套文件。
2. 完成现有私密网站的 ChatGPT 访问验证，注册或登录 Paperleaf，保存好恢复码。
3. 点击「使用 ChatGPT 登录」，在系统浏览器完成 Codex 授权后回到阅读器。
4. 导入 PDF，按需启用智能识别、自动划译、问答与汇报生成。

跨设备使用相同的 ChatGPT 网站访问身份与 Paperleaf 账号。Codex 凭据仅保存在本机，新设备需重新授权。

## 验证与已知限制

- 已完成账号和云端接口自动化测试、TypeScript 与网站构建、Codex 协议检查、Windows x64 包结构和 ZIP 完整性验证。
- 此包在 Linux 环境构建。Windows 实机启动、真实 OAuth 登录和模型推理未完成验证，不应将模拟测试等同于真实账号验证。
- 客户端尚未代码签名。若系统阻止启动，可继续使用网页版；不要关闭系统安全防护。
- 需要联网；草稿与翻译会话同时在多设备编辑时，以最后成功保存为准。
- 扫描件需要 OCR，本版不提供内置 OCR 或图表图像理解。
- 网站继续保持原有私密访问范围。
