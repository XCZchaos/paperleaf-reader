# Paperleaf 1.5.5 · 追问续用会话，回答中断时保留进展

同一篇论文里继续追问时，只要原文范围、对话记录、模型和连接设置匹配，就能沿用上一轮会话。这时客户端仅发送新问题及新引用。另开对话、改用其他页面或重启后，会根据当前原文和已保存的对话重新准备上下文。

进度区现在显示「本轮对话已就绪」或「沿用本次对话」。模型回答流中断时，会单独列出 Codex 对本轮的重试。提问失败后仍可查看本轮进度和已收到的部分回答。

「自动选择连接方式」优先使用 Codex 默认连接。同一轮连续两次出现连接失败或回答流中断后，接下来十分钟内的新请求会使用 HTTP 流式连接。当前请求继续由 Codex 处理。也可以手动固定一种方式，保留原有模型和思考强度。

桌面端查询任务进度时遇到短暂的云端账号验证故障，会保留正在执行的任务，待验证成功后继续读取。退出或切换 Paperleaf 账号仍会关闭原账号的连接。

已用真实 Codex 程序及本地模拟服务重现连续两次回答流中断，随后在同一轮恢复并完成回答。回归测试还覆盖了追问会话复用、资料范围变更、延迟到达的旧消息和手动连接设置。
