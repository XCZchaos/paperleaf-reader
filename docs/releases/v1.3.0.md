# Paperleaf 1.3.0

2026-11-04 · Windows x64

## 阅读体验

GPT 回复、翻译和笔记显示排版后的正文，支持标题、加粗、列表、表格、代码、数学公式和页码跳转。译文默认阅读模式，可切换编辑。新增书页/叶片图标、图书馆视觉与更清楚的阅读层级。

目录与笔记/GPT 侧栏可拖动调整宽度，记住本机布局；双击分隔条恢复默认，方向键微调。文本输入区域可拖动调整高度。

## Codex

显示实际生成阶段、耗时、字符数和模型提供的思考摘要；原始内部推理不接收、不输出。模型可能只返回正文。

连接窗口可强制刷新额度，展示短期/长期窗口、剩余比例、重置时间和更新时间。额度缺失或刷新失败时明确提示，不推算聊天次数。

思考强度选择基于当前模型的真实能力列表，服务端拒绝不支持的值，覆盖翻译、问答、总结、识别与 PPT。更高强度可能增加耗时和用量。

## 访问与更新

网站与源代码公开，网站编辑仅限所有者。个人 PDF、笔记和记录仍要求登录并按账号隔离。

旧版桌面菜单「检查更新与版本说明」可下载并校验本版，确认后退出安装。也可直接下载 Release 中的 EXE，覆盖安装保留个人资料。

## 验证范围

生产连接程序完成真实模型的五类阅读任务和指定思考强度测试。Markdown 渲染与安全隔离、额度缓存/强制刷新/失败/注销、公开摘要与内部推理隔离、桌面 IPC、账号与数据接口均通过自动验证。阅读器拖拽、布局记忆、排版和额度刷新通过界面夹具验证。

本构建环境用量接口返回 401，真实剩余额度未得到验证；界面明确处理此状态。本次真实模型未返回思考摘要。Windows 交互式 OAuth、用户账号权限和当地网络需在实际电脑确认；安装包未签名。
