# Paperleaf 桌面版 1.4.1

Windows 10/11 x64 安装版。下载 Paperleaf-Setup-1.4.1-Windows-x64.exe，双击并按向导安装；之后从桌面或开始菜单打开 Paperleaf。无需解压 ZIP、安装 Node.js、运行命令或输入配对码。

升级前关闭旧版 Paperleaf，安装后从新快捷方式启动。原云端文献与本机账号目录继续保留；旧免安装文件夹无需继续使用。可通过 Windows 设置卸载，本机账号目录与云端资料不会随卸载删除。

## 首次使用

1. 连接网络，打开 Paperleaf。网站入口公开，个人资料需登录后访问。新设备先通过 ChatGPT 验证身份，再登录 Paperleaf。
2. 注册 Paperleaf 用户名和独立密码，保存恢复码。已有云端文献、笔记与进度会自动保留。以后用相同 ChatGPT 访问身份和 Paperleaf 账号登录。
3. 点击“使用 ChatGPT 登录”。软件自动启动内置 Codex，并在系统浏览器打开官方授权页面。完成后回到阅读器，账号状态自动更新。
4. 导入 PDF，启用 GPT 智能识别、划词/连续翻译、问答、总结或汇报 PPT。所有 GPT 功能都使用你登录账号的 Codex 可用额度。

## 数据在哪里

- PDF、文献信息、收藏、主题、笔记、阅读进度、翻译会话、译文和 GPT 成果保存在私密云端，换电脑可继续。
- 桌面端需要联网，不提供完整离线阅读和离线冲突合并。同一篇文献同时在多设备编辑时，草稿和翻译会话以最后成功保存为准。
- Codex 授权留在当前电脑，按 Paperleaf 用户隔离。新电脑需要重新授权 Codex；此授权不会跟随文献上传。
- Paperleaf 密码与 ChatGPT/Codex 密码不同。退出 Paperleaf 不删除云端内容；“退出 Codex”清除当前本机 Codex 授权。修改 Paperleaf 密码会退出其他设备，恢复码随之更新。
- 客户端不是官方 OpenAI 软件。此版本尚未代码签名，Windows 可能显示发布者验证提示；不要关闭系统安全防护。若系统阻止启动，使用网站，或等待签名版本。

## 技术与验证范围

Electron 45.2.2 内置运行环境；官方 Codex 0.165.0 随包提供。真实 Codex 账号已通过应用连接程序完成翻译、问答、元信息、总结和 6 页汇报测试；Windows 自动测试覆盖内置 Codex 会话创建与更新安装，交互式 OAuth 和用户网络环境需在实际电脑验证。

源代码位于配套项目 desktop/、companion/、app/ 与 lib/。Electron、Codex 及 Chromium 相关许可证随程序提供。网站：https://paperleaf-xcz-reader.shamboo2003.chatgpt.site

## 阅读与更新

阅读器顶部可切换横向翻页和竖向连续阅读，会记住当前电脑的选择。文献库侧栏「版本与更新」或桌面菜单「检查更新与版本说明」可查看新版内容。更新包从同一官方网站下载，校验后点击「退出并安装」。首次从 1.1.x 升级仍需手动下载本版安装包。

Codex 面板内「测试 GPT」会发送一句示例英文，通过真实回复验证整条链路，消耗少量账号额度。

## 1.4.0 阅读体验

- GPT 回复、译文和笔记显示排版后的标题、列表、表格、代码和公式，原始 Markdown 仍可导出。
- 拖动阅读区两侧的分隔条调整目录或侧栏宽度，双击恢复默认。输入框右下角可拖动调整高度。布局会在本机记住。
- 生成时显示公开阅读进展、计划、连接重试和实际阶段；模型提供思考摘要时可展开查看。不会展示或模拟模型的内部推理。
- Codex 连接面板可刷新账号额度，显示短期和长期窗口的剩余百分比、重置时间和数据更新时间；刷新失败时不伪造数值。
- 全新书页与叶片图标，统一程序、任务栏和安装包。

Codex 面板提供当前模型支持的思考强度选择；默认档位由模型决定。设置作用于所有阅读任务，高强度可能增加耗时与用量。

- 文献问答支持持续追问和独立对话历史，按文献保存。单次请求携带最近的有限上下文，较早消息仍可查看。
- 全文翻译按 PDF 文本布局分段，中英逐段对照、页码跳转、暂停继续、失败重试与导出。扫描页需要先做 OCR。
- 修复中文标点附近的 Markdown 加粗，以及智能导入弹窗抖动。安装程序重新创建带版本化图标的快捷方式。

- 按翻译、文献信息识别、问答、总结与 PPT 功能提供账号可用的模型及思考强度建议，各功能可独立设置。
- 划译英文单词时，GPT 判断并整理释义、词性、文献语境、自拟例句与相关词。可自动或手动收录云端单词本、搜索、标记掌握、回到原文和导出。

## 1.4.1 连接与复古界面

阅读器使用暖纸色、墨绿、衬线标题与细线书目设计。内置 Codex 使用 HTTP 流式兼容连接，减少部分代理环境的 WebSocket 握手问题。进度按实际上游信息区分重试原因；连接窗口的实际测试显示首次输出、总耗时和重试次数。升级后完整退出并重新打开程序，再运行“测试 GPT”检查自己的网络。网络、额度和服务端问题仍可能产生重试。
